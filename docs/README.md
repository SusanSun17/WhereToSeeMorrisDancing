# WhereToSeeMorrisDancing
Build a website covering the county of Oxfordshire: it should let a Spectator find Morris dancing events on a map or a calendar, with event details submitted by Morris bag-men (the role within each Morris side responsible for organising events).

## Documentation map

- [plan_v001.md](plan_v001.md) and the numbered `phaseN_*_v001.md` docs — the original,
  chronological build guide (what to do, in what order, with exact commands/SQL).
- [architecture/](architecture/) — how the **finished** site actually works, organised by
  concern rather than build order. Start at [architecture/README.md](architecture/README.md).
